# تحصين · Tahseen — Live Demo

This repository hosts the **compiled static demo** of **Tahseen**, a proactive AI
financial-protection agent built for **Alinma Bank** (stops fraud, unaffordable
spending, and financial distress before they happen, over Open Banking).

**▶ Live demo:** https://abdulazizalhussein.github.io/tahseen-live/

The full source code lives in a separate private repository. This repo contains
only the built front-end bundle. The dataset is fully synthetic — no real data.

Try it: open the demo → launch the customer app → trigger a scam transfer, an
unaffordable purchase, or check financial health; then open the bank console.
